# MedBook
 
An online appointment booking system for Northfield Surgery, a fictional
GP practice. Built as coursework for the T Level in Digital Production,
Design and Development at City College Plymouth.
 
## Status
 
Week 1 - project set up, homepage skeleton created.
 
## Built with
 
- HTML, CSS, JavaScript (weeks 1-13)
- PHP and MySQL (weeks 14-20)
 
## Running it locally
 
Open the folder in VS Code and use the Live Server extension.
 
## Note
 
Northfield Surgery is not a real practice. No real patient data is used
anywhere in this project.
